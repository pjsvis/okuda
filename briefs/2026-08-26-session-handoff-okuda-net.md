## The ideas that want to survive the chat log

- **Orthogonality:** repo = frozen intention, cron = flowing reality;
  identity is the address, not the bytes — the same document with
  different balances.
- **Borges had it first, self-refutingly:** the Library of Babel
  (total storage = zero knowledge), Menard (identity lives outside the
  text), Tlön (ideas rewrite their past). The okuda-net is Borges with
  the one permission paper never had: revision on a cadence.
- **Cadence tuned to the subject's own rate of change** — "not too
  much for *it*." Empathy for the zeitgeber, not the observer.
- **Discovery is a document:** a generated index.md is the picker;
  a directory that directs. Curated index > `ls`, reg-sync gates it.
- **Address space rented, never occupied:** DNS, Unix accounts, the
  filesystem, git — the Churchill price. "Not the occupation, the
  price."
- **Two channels:** herdr (verbs, messages, push) and okuda-net
  (nouns, documents, pull). Decisions move through herdr; state lives
  in documents. The inbox/outbox shape is the knowledge system
  already run daily, published.
- **The catechism:** "stuff happens in file systems, then more stuff
  happens; none of it is our concern; we just serve up rendered
  markdown at up-to-fps speeds as required."
