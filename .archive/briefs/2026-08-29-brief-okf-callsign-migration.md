# Brief: OKF conformance migration and the callsign layer

**Created:** 2026-08-29
**TD:** td-bdfce0
**Status:** Done (shipped 2026-08-29, td-bdfce0; debrief `debriefs/2026-08-29-debrief-okf-callsign-migration.md`. Follow-up: reg-menu compositor, td-012c5d)

## What

One movement, four slices: (1) `reg-sync` becomes the frontmatter engine —
every tier document gains OKF frontmatter (`type` required, `callsign`
assigned once), lifted into the JSONL registries; (2) a generated `index.md`
per tier exported from the registries, plus the bundle-root declaration; (3)
the launcher's callsign layer — `gloam <callsign>` resolution and the footer
identity slot `silo · callsign · filename`; (4) the jump-demo menu becomes
the three-column table (slug → callsign → number), the deferred slice from
index-and-jump's close-out.

## Why

- **ADR-019 decided the shape**; this is its implementation task. Conformance
  is one required key per document; the registries stay canonical and
  private; `index.md` is an export, never a master.
- **Silo-mnemonics owns the semantics**: two codes, one referent — filenames
  are the machine code, callsigns the human code for low-bandwidth channels.
  Resolution, not derivation: assigned once, stable across renames.
- **Churn avoidance**: the table slice lands here because a two-column table
  that becomes three next week is churn — the callsign column is real data
  the day it renders.

## How

- **Frontmatter (reg-sync `--fix`)**: insert at file head
  `---\ntype: Brief | ADR | Debrief | Playbook\ncallsign: <CS>\n---`.
  Existing bold `**Date:**`/`**Status:**` lines stay — the registry keeps
  reading them; frontmatter is additive (Bun.markdown strips it on render —
  display-neutral, probe-verified). Debriefs already carry frontmatter:
  ensure the two keys, clobber nothing.
- **Callsign bootstrap (deterministic, run once per document)**: type prefix
  (`ADR`/`BRF`/`DBF`/`PLY`) + first ≤2 significant slug tokens (stopwords
  dropped), uppercase, hyphen-joined; ADRs append the zero-padded sequence
  (`ADR-BOUNDED-ANCHOR-010`); collision → numeric suffix. Frontmatter is the source
  of truth — a doc that already has a callsign is never re-derived; the
  registry is the fast index (`Entry.callsign?`, synced by `--fix`, drift
  flagged in check mode).
- **index.md export**: per tier, regenerated by `reg-sync --fix` — frontmatter
  `type: Index` + `generated: true`; body a table of date, callsign, status,
  summary from the registry. Hand-edits are overwritten on the next run.
  Bundle-root `index.md` declares `okf_version: "0.2"` and the silo `name`
  (feeds `src/root.ts` detection — already reads both).
- **Launcher callsign layer**: rooted `gloam <callsign>` maps through the
  registry to a path (unrooted: unchanged behaviour); the footer identity
  run composes `silo · callsign · filename` — `footerLine`'s reserved slot.
- **The table (probe-verified shapes)**: each row
  `| *slug* [glyph] | CALLSIGN | **NN** <!-- %%okuda-rhs:NN%% path.md --> |`
  — content → address → action; the glyph nests as a trailing mark on the
  slug (state is a property of content, not a channel); the wiring hides in
  the row's HTML comment (stripped on render; the visible number stays
  `**NN**` white-bold via the digits-only strong rule). `extractJumps`
  switches to line-scanning — token and `.md` path paired per line — which
  subsumes the paragraph form (a one-line paragraph is a line). No
  `render.ts` changes.

## Acceptance criteria

- Every tier document has parseable frontmatter with non-empty `type`;
  `just reg-sync` (check mode) green across the migrated corpus.
- Callsigns are unique across the silo and survive file rename (resolution
  keyed on frontmatter/registry, never filename).
- `briefs/index.md`, `decisions/index.md`, `debriefs/index.md`,
  `playbooks/index.md` exist as generated exports; `--fix` regenerates them
  from the registries; the root `index.md` declares `okf_version`.
- Rooted `gloam <callsign>` opens the document; the footer reads
  `silo · callsign · filename` when all three are known; unrooted and pipe
  modes unchanged.
- `just jump-demo` renders the three-column table; two-digit tokens resolve
  from table rows; backstack behaviour unchanged.
- Pure halves tested: callsign bootstrap (stopwords, ADR sequence, collision
  suffix, never-re-derive), `extractJumps` line-scan (comment-wrapped and
  bare wiring), index.md export shape. `just check` green.

## Out of scope

- `log.md` (OKF optional surface; no consumer yet).
- OKF spec surfaces beyond ADR-019's distillation.
- Cross-silo callsign qualification (badge prefixing — when a second silo
  exists).
- Voice/LLM mnemonics; callsign editing UX beyond the frontmatter escape
  hatch.
- Menu compositors other than jump-demo (status-doc keeps its list form
  until its own itch fires).
