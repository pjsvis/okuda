# Looking things up — the words, the tricks, the thousand-year head start

**Date:** 2026-09-04
**Type:** explainer

Everything in this silo that helps you find a document is a rediscovery.
The verbs, the glyphs, the tricks of the eye — all of it was invented
centuries before the terminal, by people whose only interface was ink.
We did not have to design the affordances. We had to *stop ignoring*
them. This page records the prior art, because prior art ignored is
prior art re-derived, badly, later.

## The words for looking things up

| Term | Whence | What it means here |
|---|---|---|
| **reference / cross-reference** | law, scholarship | the pointer itself — our silcrow vectors |
| **dereference** | hypertext, pointers | follow the reference to the thing it names — actuating `§NN` |
| **consult** | the library | what the reader does to a document |
| **resolve** | DNS, linkers | turn a name into an address — target string → document |
| **call number** | the stacks | the address used to fetch an item — our *callsigns* are call numbers by another spelling |
| **concordance** | the scriptorium | every word in a text, indexed with its location — the live search, compiled per keystroke |
| **finding aid** | the archive | a guide that describes a collection — the `&`-family documents |
| **selective dissemination** | 1960s library science | filtered alerts — the profession's word for a *filter* |
| **jump / go to** | the editor | the two-digit actuation |
| **retrieval, recall, precision** | information retrieval | the act, and how to measure it |

None of these is ours. All of them are ours.

## The tricks that come free with humans

1. **§ already means "see here."** A millennium of statutes trained
   every reader before we met them. A rubricated silcrow like `§11` needs no legend; the
   glyph carries its own instructions.
2. **Colour is category.** The medieval **rubricators** wrote the text
   in black, then painted the silcrows red in a second pass:
   navigation, in a colour the writer never touches. 
   Readers learned
   *colour means wayfinding* without a lesson. Our gold vector paint is
   the same trick: a reserved slot the grammar cannot address.
3. **Two digits are motor memory.** The same gesture as a keypad, a
   page number, a chapter-and-verse. `§14` is punchable before it is
   readable.
4. **Stable position is a map.** `§11` is always the eleventh
   reference; the numbers are deterministic per document, so the
   reader's finger learns the layout and stops looking.
5. **The flash is the feedback loop.** `§14 — no document to render`
   closes the loop where the eye already is. A mistake that names
   itself is a lesson, not a failure.

## The translation table

House phrasing is strange on purpose — strange is memorable, precise is
precise. But every house term must translate into everyday speech in
one sentence. If it can't, it is decoration, and decoration in a
vocabulary is worse than in a layout — people repeat it.

| House | Everyday |
|---|---|
| *actuate the silcrow* | punch the numbers and see the reference |
| *the concordance re-ranks per keystroke* | the list updates as you type |
| *u unwinds to the main document* | press u to go back |
| *99 promotes the consulted document* | hit 99 to open it in its own window |
| *the signposts step aside* | the guide pages get out of the way when you search |
| *the map re-derives; the paint is illustrative* | the numbers always match the text, because they come from it |

The test, then: **every term we mint earns its place by translating.**
The phrase that cannot be translated is not deep — it is unexplained.

## The rule going forward

Before inventing a mechanism, name the human faculty that already does
the job: colour, position, rhythm, gesture, citation habit. If the
faculty exists, the design is to *aim* it, not replace it. If no
faculty exists, the design is to teach — and teaching is a cost paid
every reader, every time. Prefer the inheritance.

The silcrow marks the reference; the number is the address; the
terminal is the document; and the reader arrives knowing most of this
already.
