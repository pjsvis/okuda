# explainers — the quiet introduction

> This folder is for humans. The playbooks are for agents: procedures,
> citations, gotchas — optimised for scanning. These explainers are
> optimised for *reading*: self-paced, jargon translated before it is
> used, one idea at a time.
>
> Unregistered by design — no callsigns (ADR-025's boundary). A register
> fires when this folder grows a named consumer or crosses ~8 documents.
> **It has fired:** twelve explainers as of 2026-11-05. The register is owed
> a decision — an index without mnemonics, or a full tier — and it is
> tracked in td rather than decided here.
>
> **Exercise out of the gate:** the tables below are jump-wired. Type the
> two digits to go; type `u` to come back. Reading the explanation and
> using the thing are the same gesture here — that is the point.

New explainers join the path. The rule is the house rule: explain the
concept before using the word, and lead with why the reader should
care.

There is no separate help system, and none is wanted: these explainers
surface in search results *alongside* the documents they explain, in
the same corpus, through the same gate. Adjacency is the delivery
mechanism — help that lives somewhere else stops being true.
