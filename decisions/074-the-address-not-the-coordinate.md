# Decision: The address, not the coordinate — citations dereference, they do not print

**Date:** 2026-10-28
**Status:** Accepted — refuses a gutter, and widens `doc-ref` to carry the line
**Enforced by:** `tests/render.test.ts` — *a citation is one affordance*: the
suffix paints inside the role, a range is one token, the five cited extensions
gild, and the sweep's own false positives (`v1.2:3`, `example.com:8080`) stay prose.

## Context

okuda renders code with no line numbers, and chroma offers them only to the HTML
formatter (`--html-lines`, `--html-line-base`, …) — in terminal mode there is
nothing to switch on. So the proposal was a gutter of our own, or nothing.

The weight behind it is not cosmetic. This silo cites in one currency:
`src/render.ts:274`. A sweep on 2026-10-28 counted **310 `file:NN` citations in the
repo**, and okuda is the tool that renders the documents containing them. Clause 1
of the protocol is that every claim about the system carries such a citation; a
renderer that cannot resolve one by eye is a renderer whose reader must take the
writer's word.

But a gutter is the wrong instrument, for a reason the renderer already knows how
to answer. `isWholeFileFence()` (`src/render.ts:1123`) means okuda knows whether a
fence **is a file** or **an excerpt**:

- **whole-file render** (`okuda src/render.ts`) — fence line *n* is file line *n*;
  a gutter would be a true address;
- **a fence in a document** — an excerpt that starts at line 40 and has `...` in
  the middle; a gutter numbering it 1..n invents a plausible, wrong address.

That second case is the whole argument. A gutter on excerpts manufactures
confident false addresses at scale — the unpaid claim, generated by the renderer —
and it would look like a feature while doing it.

## Decision

**A citation is an address, and an address is dereferenced rather than rendered.**
`path:NN` and `path:NN-MM` paint as **one** `doc-ref` token, so the whole address is
a single actable unit. No gutter, in any mode, on any flag.

The gate is that the *coordinate is not printed* — the line number exists in the
file, the editor and the citation, and does not need to appear in the margin.

## Alternatives Considered

| Alternative | Why Rejected |
|---|---|
| A gutter by default | Costs columns from the class that elides (code is cut at the glass). On an 80-column pane a 5-column gutter takes 6.5% of the budget and converts code that fits into code that elides — content traded for a coordinate. Breaks paste. |
| A gutter in whole-file mode only, behind a flag | The only version that would be *true*, and the one to reopen if the affordance fails. Refused now because it is a want, not a need: nobody has been blocked verifying a citation in the render, and the flag spends the code's own columns. The mode split is the reusable part, and it is recorded here. |
| Leave citations as prose | 310 addresses that the reader must trust. The half-actable case is worse than either extreme: `src/render.ts` gilds while `:274` does not, so the address looks resolvable and is not. |
| Widen `doc-ref` to every extension | The sweep's false positives are the evidence: version strings (`v1.2:3`) and ports (`example.com:8080`) gild under a permissive match. The list is closed and corpus-derived. |
| Emit OSC 8 with an editor URL scheme (`vscode://file/…:274`) so `cmd+click` jumps | Would work in Ghostty 1.4 today, via `link-osc8`. Refused: it reverses the long-standing no-OSC-8 refusal for links, and it puts an *editor's name and URL grammar* inside the renderer — an environment opinion in the byte stream, which is `ADR-GLASS-INK-073`'s boundary crossed in the other direction. One scheme per editor, and a document becomes unportable between machines. Recorded because it is the fastest route and the least house-shaped. |

## Consequences

**What became easier:**

- **The citation resolves at a glance.** `src/render.ts:274` is one gold token in
  the affordance register, so it can be selected whole and read into a search or
  an editor. That is the whole of what this decision delivers.
- **The record and the render agree.** Documents already cite this way; the
  renderer now colours what they cite rather than half of it.

**What this does NOT deliver — corrected 2026-10-28, hours after the fact, on a
report from the glass.** This record first claimed the token could be "matched by a
terminal `link` rule", and that is false for the terminal in use. Ghostty's `link`
regex option is **unimplemented** — `Config.zig`'s `parseCLI` for it returns
`error.NotImplemented`, and the shipped surface is `link-url`, `link-osc8`,
`link-previews`. So click matching covers URLs and OSC 8 hyperlinks, and okuda
emits neither: **there is no host-side dereference available today**, and
`cmd+click` on a citation does nothing. The gold means *this is an address, not
prose*; it does not mean *this is a link*. An actable jump is unbuilt, filed as a
task, and its route is in-silo — **a render, not an editor hand-off**: okuda already
renders code files (`wrapWholeFile`), so a wired target that names a code file and
a line arrives with that line at the top of the frame. The editor's job is
editing (`88`); navigating is reading (`BRF-CITED-JUMP`).

**What became harder:**

- **The extension list is a maintenance surface.** `json`, `toml` and the rest are
  cited in zero places today, so they stay prose. When one is needed it is one
  entry, with the grep that justifies it — the `MATH_GLYPHS` rule, applied to
  paths.
- **A line number in prose is now an address, not a word.** `10:30` is safe
  because it has no extension; `foo.ts:10` is a claim, and it is now visibly one.

**Constraints this imposes:**

- **No gutter, in any mode**, unless a report shows the affordance cannot carry
  the case. The whole-file/excerpt split is the reason, and it is a fact the
  renderer computes rather than a preference.
- **The suffix stays inside the role.** A citation painted in two registers is
  neither actable nor visibly broken.
- **The extension list stays closed and evidenced.** A new extension arrives with
  a `file:line` citation in the corpus, never with anticipation.
