## The position, in one sentence

A reader is only a reader if they can refuse — and a system is only a document
system if refusal is cheap, which it is exactly to the degree the system is
bounded.

## The claim: compliance is the proof

The reader's aphorism, as spoken: *if we are not quite bounded-domain
compliant, we are ventilator proof.* Read it as an engineering claim, because
it is one:

> **Every ventilator is a compliance failure.** Coverage is what causes the
> fan. The bounds are the valve, and a valve cannot become a fan.

The bounds compose, each one closing an axis of airflow:

| axis | the valve | the canon |
|---|---|---|
| input shape | the closed grammar | BRF-ANSI-EMISSION |
| addressable size | the cap at 80, bisect below 90 | BRF-ADDRESS-CAP |
| appearance | TFS — one colour set, no themes | speech-driven-design §5 |
| time | the gap, the skim, the freeze | BRF-SPEECH-STRIDE |
| everything | the door — `00`, double-tap zero | ADR-032, the keygrammar |

The honest limit, stated so the aphorism cannot be misused: the proof is
exactly as strong as the compliance. "Not quite compliant, still ventilator
proof" is true because every bound that *does* hold is a valve — but the
ventilator is the *later*, and later always comes. Compliance is not a status;
it is a maintenance schedule.

## The FO ladder

The reader's three complaints, each answered proportionately before the door:

| complaint | the proportionate response | and then |
|---|---|---|
| too big | the cap, the bisect, the skim to convict | `00` |
| too quick | `03` freeze — the document stays still | `00` |
| too slow | the stride, the skip, the skim | `00` |

The intermediate rungs are honest only because the door exists. A repair kit
you are forced to use is not a repair kit; a cap you cannot decline is just a
smaller ventilator. Each rung exists because the document is sometimes
salvageable — and the door exists because sometimes it is not. **Ask, then
FO**: the Derrida Question asked at reading time (*should this document be in
my reading set at all?*), with the skim as the gate's instrument — convict
without reading — and `00` the action.

## How the ladder was found: by ear

The order of discovery is the content of the design. Speech has no pointing,
so it forced naming; naming forced the unit; the unit became the stride; the
stride exposed the position; the position became the shared thing — cast,
pair, remote pair, N parties — and once the position was shared, the only
unshared thing left was the reader's own exit. Each bound was found in the
order the medium exposed it. **Speech-first is not accessibility work; it is
the discipline that found the ladder** — the voice gave up the line as glass
furniture long before the eye was ready to admit it.

## Exit is local

The N-party frame sharpens the door. Last-write-wins governs the shared
position, but every reader owns their own `00`, and nobody can hold the pair
hostage. Membership that is always voluntary is the definition of a
non-confrontational medium: a position event can carry no content, no opinion,
no appeal — there is nothing to perform over *"I am here."* Feeds collapse the
channels, putting the discussion inside the artifact where it fights for
placement; this format refuses the collapse, and the discussion rides its own
channel — the tavern, out of band, as it ever was. You cannot rage-quit a
shared cursor; you can only leave it, and the record shows a door closing.

## The gatehouse is not exempt

The right of refusal applies to the repo that guarantees it. A thing that had
evidence once and has none now, goes — soft returns had evidence; gone now;
gone. Every feature in this silo sits under the same gate as every feature it
renders, and the ejection mechanism is not exempt from ejection. That is not a
paradox; it is the maintenance schedule. The day BRF-SPEECH-STRIDE stops
earning its place, it gets the letter.

## The motto

*If it bothers you, we can turn it off.* The gate: *if it bothers you.* The
action: *turn it off.* Robyn Hitchcock wrote the outro before we wrote the
method — and the ultimate actuator was never in the grammar file anyway. It
is the reader standing up.
