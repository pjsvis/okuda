## 1. What this is

This document describes how we work. It is descriptive, not prescriptive. It does not tell anyone what to do, and it does not argue. It records a structure and a process that we actually use, so that a human or an AI arriving at the repo can understand it without being briefed.

That is the same reason the repo has `just orient`.
