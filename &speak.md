# &speak — the speech vector

The speech silo is **Blandings** (`../blandings/`): the play, the cast (Moira
narrates; Moir speaks for okuda), the library, and the pipe (`speak-md`, the
flattener that turns markdown into speech-safe prose). okuda renders what the
environment points at — the filesystem is the message bus, and no speech code
lives in this repo. This page is the pointer.

`just recite <file>` speaks an okuda document through the pipe; `just
moira-commendation` still rehearses okuda's own patron wall, which lives in
this corpus. `u` unwinds; `00` stops anything Moira is saying mid-sentence.

The boundary is a **name, not a link**: a crossing is a copy the receiver
commits, declared (`docs/2026-10-10-the-seam.md`).
